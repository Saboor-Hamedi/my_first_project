# Keyboard Shortcuts

MindForge provides an extensive suite of intuitive keyboard shortcuts so you can write, navigate, and edit at maximum speed without taking your hands off the keyboard.

---

## Global Shortcuts

- Ctrl+N: Create a new blank note
- Ctrl+S: Quick save active note to local database
- Ctrl+B: Toggle notes sidebar open or closed
- Ctrl+P: Fuzzy search across all notes
- Ctrl+R: Rename active note
- Ctrl+Shift+D: Safely delete active note
- Ctrl+,: Open Settings & Preferences modal
- Esc: Close active modal, cancel search, or return to Normal mode

---

## Text Editing & Line Manipulation

- Ctrl+]: Shift / indent line or selected text 4 spaces right
- Ctrl+[: Shift / dedent line or selected text 4 spaces left
- Tab: Indent line or insert 4-space tab
- Shift+Tab: Dedent line or selected text 4 spaces left
- Ctrl+D: Duplicate current line or selection directly below
- Ctrl+C: Copy selected text to system clipboard
- Ctrl+X: Cut selected text to system clipboard
- Ctrl+V: Paste text from system clipboard
- Ctrl+Z: Undo last edit
- Ctrl+Y: Redo last undone edit
- Ctrl+A: Select all text in active note or command line

---

## Word & Cursor Navigation

- Ctrl+Left: Jump cursor one word to the left
- Ctrl+Right: Jump cursor one word to the right
- Ctrl+Backspace: Delete entire word behind cursor
- Ctrl+Delete: Delete entire word ahead of cursor
- Home: Jump cursor to start of current visual line
- End: Jump cursor to end of current visual line
- Page Up / Page Down: Scroll viewport by full page

---

## Documentation Navigation

When reading these built-in guides:
- Click any topic in the left navigation sidebar to view that guide.
- Use j and k (or Up and Down arrow keys) to scroll smoothly.
- Type :editor or click "Return to Notes" to resume writing immediately.

---

## ShowCmd Keystroke & Command HUD

MindForge displays active and pending keyboard commands in the bottom-right HUD capsule:
- **VIM**: Multi-key operators like `ci"`, `da(`, `40j`, `dd`, `dw`.
- **VIS**: Visual selections like `vi"`, `va(`.
- **FIND**: Search queries typed via `/` or `?`.
- **CMD**: Command mode input typed via `:`.
