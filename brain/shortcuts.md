# Keyboard Shortcuts

MindForge provides simple, intuitive shortcuts so you can navigate without needing a mouse.

## Essential Shortcuts

- Ctrl+N: Create a new note
- Ctrl+S: Quick save the active note
- Ctrl+B: Toggle the notes sidebar open or closed
- Ctrl+P: Search across all your notes
- Ctrl+R: Rename the current note
- Ctrl+Shift+D: Delete the current note
- Ctrl+,: Open the Settings and preferences window
- Esc: Cancel a search, close popups, or clear selections

## Documentation Navigation

When browsing these guides:
- Click any topic in the left menu to view that guide.
- Use j and k to scroll smoothly up and down.
- Type :editor or click Return to Notes to resume writing.
