# Vim Navigation

MindForge includes an optional Vim mode for users who enjoy navigating and editing without leaving the home row.

## What is Vim Mode?

In Vim mode, the editor has two main states:
- Normal Mode: For moving around, jumping through paragraphs, and issuing commands.
- Insert Mode: For typing text normally.

## Moving Around

Use these keys in Normal mode to navigate quickly:
- h: Move cursor left
- j: Move cursor down
- k: Move cursor up
- l: Move cursor right
- w: Jump forward to the start of the next word
- b: Jump backward to the previous word
- gg: Jump straight to the top of the note
- G: Jump straight to the bottom of the note

## Switching Modes

- Press i: Enter Insert mode to start typing.
- Press Esc: Return to Normal mode to navigate.

## Useful Commands

Type a colon : followed by a command name:
- :w — Save your active note
- :doc — Open this documentation reader
- :editor — Return to your notes editor
- :q — Quit the application
